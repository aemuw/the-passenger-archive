# Design notes

## Pitch
Endless train. 10–15 hand-crafted carriages (1.5–3 h, replayable). Each carriage: one victim, one hidden
killer among the passengers, one carriage rule. Passengers' stories slowly hint at who the hero is.
The hero's ticket has an erased destination.

## Death
Break the rule (or accuse wrongly) → the carriage's killer kills the hero **in the same way the victim died**.

## World rules (never broken)
1. The train always moves.
2. You cannot go back.
3. Everyone has a reason to be here.
4. The conductor never lies.
5. History cannot be changed.
6. Every carriage holds something from the past.
7. The hero cannot just get off.

## Look
- Late-90s survival horror + PS1 + VHS/analog unease. First person, rare fixed-camera beats.
- Palette: dirty yellow, grey-green, dark brown, cold blue night. Reality = yellow-green, memory = cold blue,
  danger = amber/red, supernatural = near-monochrome.
- Light is the main tool: dead lamps, dark gaps between carriages, faces half in shadow, window glare.
- No HUD. Ticket / notebook only.

## Sound
Train ambience ~90% of the time; it may thin out to silence before something happens but never fully vanishes.
Music only at key moments; one 3–5 note motif reused (menu, piano memory, distorted nightmare, faint finale).

## Pacing
calm → curiosity → strangeness → human story → tension → horror → calm → next carriage.
Not every carriage scares: some sad, some odd, some cosy.
